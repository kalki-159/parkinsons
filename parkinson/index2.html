About This Project

This frontend records or uploads a video and sends it to your backend model endpoint.

Input

Webcam recording (WebM) or uploaded video (any browser-supported format).

API Contract

POST /predict-video with multipart/form-data field video.

Output

JSON like: {"label":"Parkinson","risk_score":75.2,"confidence":93.1}

Medical Disclaimer

This is a screening/demo UI. It does not provide a diagnosis.

Privacy: This UI sends video to whatever backend URL you configure. Use HTTPS in production.
